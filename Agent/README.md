## 一张图看各层关系

```text
用户意图 → Goal → Plan / Subgoals → Graph（阶段与路由）
                                   ↓
                               Loop（局部行动）
                                   ↓
                         工具 / RAG / 业务系统

Context：每轮给模型的工作集       State：当前任务事实与控制状态
Harness：权限、预算、执行、追踪与恢复
MCP：接入外部能力             A2A：委托独立 Agent
```

**选哪篇：**想知道“下一步怎么决定”，读 Loop；想知道“整个任务如何调度”，读 Graph；想知道“动作如何安全执行”，读 Harness。更多易混淆概念和具体问题见[知识点索引](<知识点索引.md>)。
